ASX Dashboard — Setup

Everything below happens in a web browser. No Terminal.

About 20 minutes, once

When you're done you'll have a dashboard at a web address you can open from any device, that updates itself on a schedule forever, for free — with no server and no billing cycle to run out of.

1

Create a GitHub account · 2 min

Go to github.com/signup and sign up. The free plan is all you need.

Verify your email. GitHub won't run scheduled jobs until you do.

2

Create the repository · 2 min

  1. Go to github.com/new
  2. Repository name: asx-dashboard
  3. Select Public
  4. Leave everything else alone. Click Create repository.
Why public? That's what makes the automation and hosting free. It's safe — only public market data gets published. Your holdings are stored in your browser and never uploaded.
3

Upload the files · 5 min

On the empty repository page, click the link that says uploading an existing file.

Open the asx-dashboard folder I sent you. Select everything inside it (Cmd + A) and drag it into the browser window.

One catch, and it matters. macOS hides folders whose name starts with a dot, and there's an important one called .github — it holds the schedule. Press Cmd + Shift + . in Finder to reveal hidden files before you select everything. The same shortcut hides them again afterwards.

After uploading, check the file list includes a .github folder. Without it nothing will run on a schedule.

Scroll to the bottom and click Commit changes.

4

Turn on GitHub Pages · 2 min

  1. In your repository, click Settings — the one on the repo, top right, not your account settings
  2. Left sidebar → Pages
  3. Under Build and deployment:
    • Source: Deploy from a branch
    • Branch: main, then change the folder dropdown from / (root) to /docs
  4. Click Save

Wait 2–3 minutes, then reload that page. It'll show your address:

https://<your-username>.github.io/asx-dashboard/

It'll say "no data yet" for now. That's expected — nothing has fetched anything.

5

Run the first data build · 5 min

  1. In your repository, click the Actions tab
  2. If it asks, click the green I understand my workflows, go ahead and enable them
  3. Left sidebar → Refresh dashboard data
  4. Right side → Run workflow ▾ → leave mode as full → green Run workflow
This first run takes 5–10 minutes. It downloads 180 days of ASIC short-position history and builds the stock universe from scratch. Every run after this is under a minute.

When it finishes with a green tick, open your dashboard address. Data — including six months of short-interest history backfilled from ASIC's archive, and a Track record panel under Research & monitor showing how the signals would have performed against the market over that period.

6

Add your holdings · 2 min

On the dashboard: Portfolio tab → Edit holdings → add each position (code, units, average buy price) → Save.

Stored in your browser only. Use Export to save them to a file and Import to load them on another computer.

7

Share it · 1 min

The dashboard address itself is public — send it to anyone and they'll see the short-interest charts, the signals, the watchlist, all of it. They will not see your portfolio, because that isn't published.

To share the portfolio too: Portfolio → Edit holdings → Copy share link. That link carries your positions inside it, so whoever opens it sees the complete dashboard with the Portfolio tab filled in.

Why not just publish the holdings? Because the repository is public, and anything committed to a public repository stays in its history permanently, even if you delete it later. The share link gives the same result for the person you send it to, without your positions and cost base sitting at an address anyone could find. Treat the link like the information it contains.
That's it. From here it runs itself.

The Force refresh button on the dashboard opens the workflow so you can run it on demand.

Making changes later

Any file can be edited on GitHub directly — click the file, click the pencil icon, edit, Commit changes. The site redeploys within a minute. To replace files wholesale, use Add file → Upload files again.

Two things worth knowing

Why the repository is public. GitHub gives unlimited automation minutes and free hosting to public repositories; private ones are metered and Pages needs a paid plan. What gets published is ASIC short-position data, ASX prices, and the signals computed from them — all public information already. Your holdings never leave your browser, which is why the Portfolio tab starts empty on a new device until you import them.

A dormancy rule. GitHub switches off scheduled workflows in repositories with no activity for 60 days. Yours commits data every weekday, so this shouldn't trigger. If it ever does, GitHub emails you and there's a button to switch it back on.
